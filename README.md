# DIMENSION-LENS

**写真は、五次元にいる。**

画像を添付し、次元スライダーを動かすと、その画像が「その次元での姿」になる ——
ブラウザだけで動く静的な可視化作品。姉妹作 [DIMENSION](https://github.com/ops324/dimension) の派生。

DIMENSION は「高次元の図形を人間に見せる」作品だった。こちらは逆向きの問いで、
**人間が毎日見ているもの（写真）が、実はもっと高い次元にいる**ことを見せる。

## 中核

写真は写像 `I: [0,1]² → 色空間` であり、そのグラフ

```
Γ = { (u, v, L(u,v), a(u,v), b(u,v)) }  ⊂  R² × OKLab = R⁵
```

は **R⁵ の中の2次元曲面**である。これは画像処理で標準的な joint spatial-range space の
定式化で、何も足していない。天井の 5 は「色が 3 次元だから 2+3=5」という事実であって、
任意に選んだ数ではない。

`dimLevel ∈ [0,5]` の一本のスライダーが、その曲面を連続に上り下りする:

| n | | |
|---|---|---|
| 0 | MEAN | すべての画素の光を足して割った、この写真のたった一色 |
| 1 | LINE | 縦の列をそれぞれ一色にたたむ。写真が一本の線になる |
| 2 | **PHOTOGRAPH** | **あなたの写真そのもの ── ここが錨** |
| 3 | RELIEF | 明るさを三つ目の軸に立てる。明るい場所が峰、暗い場所が谷 |
| 4 | CHROMA | 赤みと緑みを、四つ目の軸へ |
| 5 | GRAPH | 五本の軸のすべて。写真がもともと住んでいた曲面の、全身 |

SO(5) の回転平面にはそれぞれ意味がある。`(0,1)` は普通の画像の回転、`(0,2)` は明暗が形になる、
そして **`(3,4)` は色相回転そのもの**。通常の回転と色相回転が同じ群の部分群であり、
その間を連続に補間できる。

## 画像は端末から出ません

サーバがありません。解析もありません。通信する仕組みそのものがありません。
画像はブラウザのメモリ内でだけ処理され、タブを閉じれば消えます。

これを約束ではなく確かめられる事実にするため、次の3つを置いています:

1. **CSP** — `default-src 'none'` を基点に、`img-src` を含めて外向きを閉じる
   （`connect-src` だけでは `new Image().src=` による送信が塞げないため）
2. **ビルド成果物の静的検査** — `dist/**/*.js` に通信 API が現れないことを CI で検証する
3. **違反イベントの実測** — preview ビルド上で `fetch` と外部画像読み込みの両方を試し、
   どちらも `securitypolicyviolation` が発火することを確認する

**CSP にも塞げない穴があります**（ページ移動・`window.open`・WebRTC）。
このコードはそのどれも使いませんが、「使えない」のではなく「使わない」であることは正直に書いておきます。
また、このページは GitHub Pages で配信されているので、GitHub はページ取得そのもの ——
IP アドレスとブラウザの種類 —— を記録します。画像はその記録に含まれませんが、訪問した事実は残ります。

## 開発

```bash
npm install
npm run dev        # :5173
npm run preview    # :4173 — CSP が入るのはこちら。プライバシー検証は必ず preview で
npm test           # vitest
npm run bench      # 融合カーネルのマイクロベンチ（ティア表の根拠）
npm run build      # tsc && vite build
```

**1フェーズ = 1ブランチ = 1 PR。** `main` へ直接コミットしません。
マージ前の品質ゲートは4点 —— vitest 全緑 / build 成功 / 実ブラウザ測定の数値を PR に貼る /
コンソールエラーゼロ。測定が予算を外したらマージしません。

詳細な設計・罠・到達水準は [SPEC.md](./SPEC.md) にあります。
特に巻頭の**到達水準表**（A=実測 / B=機構確認 / C=未検証）は、この作品が何を証明できていて
何をまだ証明できていないかの唯一の正典です。
